# AI Workshop | Media Hub

موقع توثيقي وتعليمي تفاعلي لورشة الذكاء الاصطناعي، تنظيم **Media Hub | نادي التطوع** بالتعاون مع **جمعية أنا مصري للتنمية والتدريب**.

مبني بـ **React + TypeScript + Tailwind CSS**، بدون قاعدة بيانات — كل المحتوى في ملفات بيانات منفصلة سهلة التعديل.

---

## 1) كيف أشغل المشروع

يحتاج المشروع Node.js (نسخة 18 أو أحدث).

```bash
npm install        # تثبيت الحزم لأول مرة
npm run dev         # تشغيل المشروع محليًا للمعاينة (http://localhost:5173)
npm run build        # بناء نسخة الإنتاج داخل مجلد dist/
npm run preview       # معاينة نسخة الإنتاج محليًا
```

---

## 2) أين أغيّر اسم الورشة؟

في الملف: `src/data/site.ts`
```ts
export const site = {
  siteName: "AI Workshop | Media Hub",
  workshopName: "ورشة الذكاء الاصطناعي", // <-- هنا
  tagline: "من الفكرة إلى التطبيق",
  ...
}
```

## 3) أين أغيّر التاريخ والمكان والوقت؟

نفس الملف `src/data/site.ts`:
```ts
workshopDate: "26 سبتمبر 2026",
workshopTime: "11:00 صباحًا",
workshopLocation: "جمعية أنا مصري",
```
هذه القيم تظهر تلقائيًا في الصفحة الرئيسية (Badges) وفي أي مكان آخر يستخدمها.

## 4) أين أضيف روابط الأدوات؟

- الأدوات الأساسية والإضافية: `src/data/tools.ts` — عدّل حقل `link` لكل أداة.
  - إذا لم يتوفر رابط مؤكد، اتركه كما هو: `"[ضع رابط الأداة هنا]"` وسيظهر ذلك بشكل واضح بدل الزر.
- روابط الأدوات داخل الأجندة: `src/data/agenda.ts` — حقل `link` لكل فقرة.

## 5) أين أضيف تصميم الإعلان؟

الصورة الحالية موجودة في: `public/assets/poster-workshop.jpg`
لاستبدالها: استبدل الملف بنفس الاسم، أو غيّر المسار في `src/data/site.ts` → `assets.posterWorkshop`.

## 6) أين أضيف تصميم الأجندة؟

لم يتم إرفاق تصميم جاهز للأجندة بعد؛ الأجندة معروضة حاليًا كـ Timeline مبني بالكامل من البيانات في `src/data/agenda.ts`.
إذا توفر تصميم جاهز لاحقًا (كصورة)، ضعه في `public/assets/` واستخدمه داخل `src/pages/Agenda.tsx` مثل باقي الصور.

## 7) أين أضيف الفيديو؟

في الملف: `src/data/documentation.ts`
```ts
export const teaserVideo = {
  url: "",         // ضع رابط embed هنا (مثال: يوتيوب أو Google Drive)
  isReady: false,   // غيّرها إلى true عند جاهزية الفيديو
};
```
بمجرد تغيير `isReady` إلى `true` ووضع رابط الفيديو، سيظهر الفيديو تلقائيًا في قسم "مفاجأة Media Hub" بدل النص المؤقت.

## 8) أين أضيف الصور؟

- ضع أي صور جديدة داخل: `public/assets/`
- صور فريق التنفيذ: أضف المسارات في `src/data/team.ts` → `teamGalleryPlaceholders`
- روابط ألبومات/فيديوهات التوثيق (Drive / YouTube / Facebook): `src/data/documentation.ts` → `mediaLinks`

## 9) أين أعدّل أسماء فريق التنفيذ؟

في الملف: `src/data/team.ts` — عدّل أو أضف عناصر في مصفوفة `team` (الاسم + الدور + ملاحظة اختيارية).

## 10) أين أضيف نتائج الورشة؟

في الملف: `src/data/documentation.ts` → مصفوفة `outcomes`.
القيمة الافتراضية لكل نتيجة هي `"سيتم التحديث بعد الورشة."` — استبدلها بالنتيجة الفعلية بعد انتهاء اليوم فقط، ولا تضع أرقامًا وهمية.

## 11) كيف أرفع المشروع على GitHub؟

```bash
git init
git add .
git commit -m "AI Workshop | Media Hub — initial version"
git branch -M main
git remote add origin <رابط المستودع الخاص بك>
git push -u origin main
```

## 12) كيف أنشره على Vercel لاحقًا؟

**الطريقة الأسهل (من خلال الموقع):**
1. ارفع المشروع على GitHub كما في الخطوة السابقة.
2. افتح vercel.com وسجّل دخول.
3. اختر "Add New Project" ثم اربط مستودع GitHub الخاص بالمشروع.
4. Vercel يكتشف أن المشروع Vite تلقائيًا (Build Command: `vite build`, Output: `dist`) — لا حاجة لتغيير أي إعداد.
5. اضغط Deploy، وستحصل على رابط عام للموقع خلال دقائق.

**أو عبر الأوامر مباشرة (Vercel CLI):**
```bash
npm i -g vercel
vercel         # لنشر نسخة معاينة
vercel --prod   # لنشر النسخة النهائية
```

ملف `vercel.json` موجود بالفعل في جذر المشروع ويضمن عمل كل الصفحات (`/agenda`, `/tools`, `/team`, `/documentation`) بشكل صحيح عند فتحها مباشرة برابطها.

## هيكل المشروع

```
src/
  data/             ← كل بيانات الموقع (عدّل هنا فقط لمعظم التحديثات)
    site.ts          بيانات الورشة الأساسية + البطاقات التعريفية
    agenda.ts         أجندة اليوم
    tools.ts          أدوات الذكاء الاصطناعي
    team.ts           فريق تنفيذ الورشة
    faq.ts            الأسئلة الشائعة
    applications.ts    تطبيقات عملية داخل اللجان
    documentation.ts    التوثيق والنتائج (فارغ وجاهز للتعبئة بعد الورشة)
  components/        مكونات مشتركة (Navbar, Footer, Accordion...)
  pages/            صفحات الموقع (الرئيسية، الأجندة، الأدوات، الفريق، التوثيق)
public/assets/       الشعارات وصورة الإعلان
```

## ملاحظات

- الموقع عام بالكامل، بدون تسجيل دخول، ولا يحتوي على رابط جروب الورشة.
- التصميم متجاوب بالكامل (هاتف / كمبيوتر / شاشات عرض كبيرة) ومناسب للعرض على شاشة أثناء الورشة.
- الاتجاه RTL بالكامل، والخط المستخدم Cairo.
- زر تبديل الوضع الفاتح/الداكن متاح من شريط التنقل.
